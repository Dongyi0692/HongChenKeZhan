## 当前操作

| 输入 | 作用 |
|---|---|
| WASD | 相对镜头跑步，人物朝向移动方向；不耗体力 |
| 鼠标移动 | 自由转视角；锁定时上下调整，水平朝向由锁定目标控制 |
| 鼠标中键 | 锁定/解除锁定可见敌人 |
| Tab | 切换可见敌人 |
| 左键 | 轻击 |
| 右键 | 每按一次重击一式；依次推进四式，可穿插左键轻击 |
| F | 突进斩；成功起招消耗30体力，无冷却 |
| Q | 按住格挡；迎面来招前0.18秒内抬起可精准格挡 |
| 左Shift | 闪避，消耗22体力 |
| Space | 跳跃，消耗18体力；对白中继续 |
| E | 推开后门、账本、交谈、推进对白 |
| R | 战斗/失败时重试当前段；探索阶段重开 |
| Esc | 暂停/返回 |
| F1 | 操作说明；也可从暂停菜单打开 |

精准格挡角度比普通格挡窄，成功能打断对方并造成短暂硬直，挡中体力消耗更少。长按仍是普通格挡，反复快速点按不能刷新精准窗口。受伤会中断出招；保留 v4 的精准格挡反震和敌人受伤后还击优先级。

连续轻重攻击保持右键的重击段数，可以按“左—右—左—右—左—右—左—右”混合出招。停手约 2.2 秒、受到伤害或切换锁定/实际攻击目标后，右键从第一式开始。提前按下下一招或闪避会在允许的衔接窗口尝试执行，不能随时打断有效攻击段。体力不足的闪避不会继续占住动作队列。

锁定金框不增加剑的攻击距离，墙体继续阻挡攻击。突进斩没有冷却，但仍须体力、落地和动作衔接条件满足。下蹲和空中攻击未提供。

## 只关闭逐次重击

停止 Play，在 Unity 顶部菜单选择“红尘客栈 > 战斗 > 恢复整套四连招”，保存场景后再试玩。此时右键一次播放完整四式，其余按键、输入衔接、镜头、画质和剧情保持当前版本；教学说明也会跟随开关变化。

重新启用选择“红尘客栈 > 战斗 > 启用逐次重击”并保存场景。也可在 Player 的 PrototypeFighter 组件切换 Use Sequential Heavy。详见 `Docs/2026-11-17_逐次重击单独回退说明.txt`。

浅落地也有独立开关：停止 Play，在 Player 的 PrototypeFighter 组件关闭 Use Light Landing，可恢复完整落地片段。不要为回退这部分覆盖整个旧脚本。本轮改前备份在 `Backups/2026-11-18_before_motion_flow`。

入栈→E阅读账本→小兵对白→8项实际操作教学→第一战→斗笠客从前门入栈、对白、第二战→E推后门并走到门外→五兵前门入堂，斗笠客独自掩护→听见呼喊后返回，E推开后门→在大堂靠近斗笠客，完成回援对白→正式加入第三战→结交对白揭示虬髯客身份→再次E开后门并实际离栈→独立“风尘未歇”终幕及AI说明→约2.8秒后结算。

三段正式开战都恢复主角满血。每段失败只重试当前段；重试满血满体力，第三战不重播离栈与回援。小兵始终敌对。第三战同伴900生命并保留最低1生命保护，仍会受击。掩护阶段小兵也有存活保护，主角正式加入后取消；主角从门外自行回屋，不被流程传送。

前门从第一战开始一直开到第三战获胜，战间对白、回援和本段重试时也保持开启。战前、获胜后和重新开局时，前门按内外约 3 米的距离自动感应。

运行文本使用红衣。最新正文方向见 `Docs/Story/红尘客栈_剧本替换版_2026-11-18.docx`，离栈、回援与最后离场方向已接入；该文档保留的旧简介和附录仍属旧版说明。11月17日稿与原DOCX继续保留，本轮没有新制Word。
