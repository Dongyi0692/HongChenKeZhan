## 操作

| 输入 | 当前作用 |
|---|---|
| WASD | 相对镜头方向跑步，人物转向移动方向 |
| 鼠标 | 旋转镜头 |
| Space | 跳跃；对话时推进对白 |
| 鼠标左键 / 右键 | 轻击 / 完整重击连招 |
| 按住 Q | 格挡并消耗体力；松开退出格挡 |
| Shift | 按移动方向闪避；无方向输入时后撤，消耗22点体力 |
| F | 突进剑技 |
| E | 交互、交谈、推进对白 |
| R / Esc | 重置流程 / 暂停或返回界面 |

下蹲已移除。跑步不消耗体力；跳跃、格挡和闪避消耗体力。主角闪避暂用适配新骨架的旧程序动作，效果尚待用户确认。空中攻击不属于本轮实现。

## 剧情与角色

1. 红拂抵达客栈，与驻守小兵交手，配合教学。
2. 追兵抵达，与红拂决斗；红拂失败即结束，不进入后续回援。
3. 红拂获胜后，追兵放行并抵挡后续小兵；红拂返回帮助追兵。

只有胜利后的追兵转为友军。所有小兵始终敌对，每名小兵都有横砍与地面单次斜劈。主角与精英另有突进技能，小兵没有技能。
