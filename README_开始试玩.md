## 操作

| 输入 | 当前作用 |
|---|---|
| WASD | 相对镜头方向跑步，人物转向移动方向 |
| 鼠标 | 旋转镜头 |
| Space | 跳跃；对话时推进对白 |
| 鼠标左键 / 右键 | 轻击 / 四式重击；重击段间可用格挡或闪避退出 |
| 按住 Q | 保持面敌格挡，可缓慢调整位置；持续及承受攻击时消耗体力 |
| Shift | 按移动方向闪避；无方向输入时后撤，消耗22点体力 |
| F | 突进剑技 |
| E | 交互、交谈、推进对白 |
| R / Esc | 重试当前战斗段 / 暂停或返回界面；探索阶段 R 从整局重新开始 |

下蹲已移除。跑步不消耗体力；跳跃、格挡和闪避消耗体力。主角闪避暂用适配新骨架的旧程序动作，效果尚待用户确认。空中攻击不属于本轮实现。

## 剧情与角色

1. 红拂抵达客栈，与驻守小兵交手，配合教学。
2. 教学胜利后追兵从门外走入，站稳并面向红拂交谈，再决斗；红拂失败可重试本段，不进入后续回援。
3. 红拂获胜后，追兵放行并抵挡后续小兵；红拂返回帮助追兵。

只有胜利后的追兵转为友军。所有小兵始终敌对，每名小兵都有横砍与地面单次斜劈。主角与精英另有突进技能，小兵没有技能。

## 动作与编辑位置

本轮接入17个实际动作片段，以 Aholo 导出资源和 Unity Humanoid 重定向驱动。探索普通站姿与战斗持剑待机分开。角色控制器负责世界位移与碰撞，攻击前冲已与骨骼姿态分离。
