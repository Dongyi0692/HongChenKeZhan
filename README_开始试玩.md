## 打开当前版本

1. 先克隆仓库并运行 `git lfs pull`，再在 Unity Hub 添加克隆后的仓库根目录。默认 `main` 是本轮交付版；不要误开旧 `FengChenInn` 工程。
2. 使用 **Unity 6.3 LTS（6000.3.25f1）**。
3. 打开 `Assets/_Game/Scenes/InnDuel_Stage12_CollisionLighting.unity`，点击 Play，再选“开始游戏”。需要时点击游戏画面捕获鼠标。

只有 `Builds/2026-11-17_v1/` 是本次新版，其他历史试玩包保留原样。旧说明中的 ActionLab、F 开战和下蹲不适用于当前版本。队友克隆后打开自己的工程目录，并确认 Git LFS 文件已下载。

## 操作

| 输入 | 当前作用 |
|---|---|
| WASD | 相对镜头方向跑步，人物转向移动方向 |
| 鼠标 | 转动镜头 |
| Space | 跳跃；对白中推进下一句 |
| 左键 / 右键 | 轻击 / 四式重击 |
| 按住 Q | 保持面敌格挡，可缓慢调整位置；持续及挡中时消耗体力 |
| 左 Shift | 有方向时向该方向闪避，无方向时后撤；消耗体力 |
| F | 突进斩，成功起招消耗 30 点体力，无冷却 |
| E | 推门、翻阅账本、读完账本、交谈或推进对白 |
| R | 战斗或失败后重试当前段；探索阶段从整局开头重新开始 |
| Esc | 暂停/返回；阅读账本时暂时退出，需读完才能推进剧情 |
| F1 | 查看操作说明 |

跑步不耗体力。跳跃、格挡、闪避和 F 消耗体力；F 起招失败不扣费，但仍需落地、体力足够并等待当前动作允许衔接。重击段间可用格挡或闪避放弃后续攻击。下蹲和空中攻击未提供。

## 按这个顺序体验

1. 入栈后走到账台，按 E 翻阅账本，再按 E 读完合上。此时的小兵尚未提前在大厅开战。
2. 小兵现身，推进 4 句对白。随后完成 8 个实操教学：移动、转镜头、轻击、重击、格挡、闪避、跳跃、突进斩。按提示真正完成动作并等待收势，才会进入下一步。
3. 完成教学后与小兵交手。首战获胜后，等精英追兵从门外走进来，交谈后决斗。
4. 获胜后按引导走向**后门**，靠近按 E 开门并离开；回头帮助追兵迎战 5 名来兵。
5. 追兵此时是友军，600 HP、最低 1 HP 剧情保护，仍会受击掉血。清除来兵并靠近追兵后完成结交和结算；即使他先打完，也需要你上前交谈。

三段正式开战都会回满主角生命，正常转段不额外补体力。失败后选“重试本段”或按 R，恢复本段，保留之前的胜利；重试主角满生命、满体力。检查点不跨游戏运行保存。

阅读账本及对白时，主角保持现有自然直立站姿并握剑；从行走或跳跃进入也不会冻结成迈步、跳跃或落地姿态。关闭阅读/对白后恢复控制。账本美术目前为占位，没有新增人物过场动作。
