# 风尘客栈

Unity 可编辑工程。使用 Unity Hub 添加本文件夹，编辑器版本为 **Unity 6.3 LTS（6000.3.25f1）**。打开 `Assets/_Game/Scenes/InnDuel.unity`，在 Unity 中点击 Play。

当前版本包含主角、小兵、精英及客栈场景。WASD 跑步，鼠标调整视角，Space 跳跃，Shift 闪避，Q 格挡，鼠标左右键轻击与重击，F 技能，E 交互。
