## 范围与实现

本轮在正式场景实际使用的 `InnInterface` 上调整外观，保留既有剧情、按钮回调、状态切换和动态数据。主菜单、HUD、账本、操作指引、角色控制、战斗与 AI 没有作为本轮美术修改目标；正式场景文件没有改动。

| 页面 | 完成内容 | 保留的功能 |
| --- | --- | --- |
| 02 剧情序章 | 原插画、排版及按钮保持原状 | 六段剧情、逐段显示、继续/跳过、音乐衔接 |
| 06 剧情对话 | 深色半透明底板、细金边、人物签、页数、右下角继续提示；保留可见的 3D 场景 | 动态人物名和对白、E 继续、战前/战后/失败回调、对白期间操作限制 |
| 07 暂停 | 压暗实时场景、纵向文字菜单、朱红选中项 | 继续、操作说明、设置、回标题；原有 Esc 与失焦暂停逻辑 |
| 08 设置 | 按确认图实现左右分栏、分类笔刷、细分隔线和柔化深棕背景；背景由项目原有无字插画另行处理 | 图像、声音、控制、其他共四类；画质、分辨率、显示模式、灵敏度、垂直反转、总音量、音乐、雨声、UI 音效和胜利音乐 B 均保留原存取逻辑；主菜单和暂停共用 |
| 09 失败结算 | 冷色夜景、克制标题和按钮 | 原失败对白之后显示、动态失败文案、重试当前段、退出游戏 |
| 10 终幕 | 黑场后显现雨夜插画、原终幕标题、AI 制作说明和自动继续提示 | 后门离场触发、约 2.8 秒自动进入胜利结算 |
| 11 胜利结算 | 雨夜插画、「此夜得脱」标题、双按钮 | 真实交手结果与战斗用时、再玩一次、回标题、原胜利音乐逻辑 |

所有界面文字仍由 Unity 文本组件绘制。没有把效果图中烘焙的按钮或错字直接盖到游戏上，也没有改动剧情原文。
