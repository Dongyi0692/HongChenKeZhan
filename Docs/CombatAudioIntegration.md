# 战斗音效与序章音乐（2026-11-18）

## 素材与分类

原始 7 个文件逐字节复制到 `Assets/_Game/AudioSources/Combat/`。处理后 15 个单声道 48 kHz / 24-bit PCM WAV 放在 `Assets/_Game/Resources/CombatAudio/`，Unity 使用预解压 PCM。原始 AIFF、MP3、WAV 不覆盖。

| 原录音 | 处理后 | 使用方式 |
|---|---|---|
| clean-fast-swoosh.aiff | LightSwing/LightSwing.wav | 轻攻击挥剑 |
| gaussthewizard__swing.mp3 | HeavySwing/HeavySwing.wav | 重攻击首段 / 单段重攻击 |
| 格挡.wav | Block/Block.wav | 真实成功格挡事件 |
| sword-impact.wav | Hit/Hit.wav | 真实伤害命中事件 |
| 连续挥剑声.wav | Combo/Combo_01..05.wav | 四式重击后续段，剑技选择独立片段 |
| 闪避.wav | Dodge/Dodge.wav | 实际接受的闪避动作 |
| metal-blade-drop.wav | Drop/Drop_01..05.wav | 独立武器落地碰撞组件，随机且不连续重复 |

连续挥剑录音有 5 个主要声响，不整段播放。武器落地保留每次落地内部的自然弹跳和衰减，单段约 0.79–1.23 秒；不将一次落地中的弹跳误拆为多个独立落地动作。

闪避提取原录音 0.025–0.56 秒，增益约 +14.92 dB；移除后续长静音和低电平残留。统一按响亮的 50 ms 窗口平衡响度，并以约 -3.74 dBFS 峰值上限限制增益。边界做短防点击渐变。完整时间、增益、源文件 SHA256 见 `AudioVerification/combat-segments.json`。

轻/重候选依据瞬态、包络长度和在现有动作中的播放输出匹配：轻挥主要峰值在裁切后约 60 ms，重挥约 150 ms。验证包含真实声音输出采样，但不等同于人工主观试听；可按最终扬声器与混音偏好继续微调。

## 触发机制

- `CombatAudioSystem` 自动建立最多 8 个独立 3D 声源，并给现有和动态生成的 `CombatActor` 添加 `CombatAudioEmitter`。
- 现有轻击、重击、剑技动画均没有 Animation Events；复用 `AttackStarted` 与 `AttackPoseSampled`。后者提供真实 Playables 动画时钟和采样姿态。使用现有 `hitWindows` 的挥剑段定位声音前奏，不新增伤害窗口、不使用协程延时推测命中。
- 红拂女四式重击现有窗口起点约为 0.367、1.033、1.733、2.567 秒。当前逐式重击模式下，每次被接受的重击输入播放对应一式：首式 HeavySwing，随后三式使用拆出的 Combo 片段。挥空也有挥剑声；没有后续输入或动作中断时不会排队播放剩余声音。
- 命中只订阅被击者 `Damaged`，要求来源非空且实际伤害 > 0。格挡只订阅被击者 `Blocked`。仅按住格挡、无敌闪避未受伤、攻击落空均不会制造接触声。
- 闪避只订阅 `PrototypeFighter.ActionPerformed(Dodge)`，动作未接受时不播放。
- 原 UI 的提示文字照常；当新的战斗音频系统存在时关闭合成提示音播放，避免命中/格挡双响。
- 战斗音量有 0.8 的全局声源音量预算，每个片段峰值 ≤ 0.65，最多 8 个声源。连续攻击不会无限堆叠，优先保留命中和格挡。该预算针对战斗音效，并非对整场音乐/雨声做总线硬限幅。
- 2026-11-18 Play Mode 听感修正：原声源增益约 0.32–0.36，明显低于脚步声源 0.8。现将挥剑、命中、格挡增益分别调到 0.55、0.65、0.60；闪避与落地为 0.42、0.48。起音直接按目标增益播放，同一帧再按原有 0.8 预算平衡并发声源。原始和处理后的录音均未改动。
- 暂停停止战斗声源；不会在暂停期间推进挥剑采样。

## 武器落地的实际状态

项目尚无脱手、缴械或武器实体落地机制，武器仍附在角色上。因此没有把“角色死亡”当作“武器碰到地面”。

`WeaponDropAudio` 已实现并通过真实 Rigidbody 碰撞测试。未来真实脱手武器应在同一物体上配置 Rigidbody、Collider 和该组件；首次有效朝上地面接触才播放，后续小弹跳不重复。重新拾起再投落时调用 `Arm()` 或重新启用组件。现在的正式战斗不会凭空发出武器落地声。

## 序章背景音乐

主菜单“开始游戏”不再提前关闭音乐，`InnInterface.Show(Prologue)` 继续启用现有菜单音乐。序章保留现有音乐与持续雨声；真正进入可操作剧情场景时才用已有约 2 秒淡出。原音乐和雨声音频、交叉循环及设置音量功能均保留。

## 验证

Unity 菜单 `Tools/红尘客栈/音频/验证战斗与序章 (Play Mode)`。测试在 Stage12 的真实控制器、Playables 和剑刃碰撞逻辑中执行；目标是仅存在于 Play Mode 的敌对碰撞胶囊，武器落地使用临时刚体。不会保存场景、改写战斗判定或攻击参数。
